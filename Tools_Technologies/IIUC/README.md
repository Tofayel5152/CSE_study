# 🏛️ IIUC Portal / Web Application

A web interface project built for **International Islamic University Chittagong (IIUC)**, featuring user authentication views as part of the **CSE Study** repository.

## ✨ Features
- Clean institutional branding with IIUC logo representation.
- Built-in authentication navigation including **Login** and **Signup** pages.
- Responsive layout designed for desktop and mobile web views.

## 🛠️ Tech Stack
- **HTML5** — Structure & page markup
- **CSS3** — Styling, alignment, and custom asset integration
- **JavaScript** — Dynamic behaviors and client-side interactions
