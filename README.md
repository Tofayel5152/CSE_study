A structured, course-by-course repository containing code snippets, lab assignments, project files, lab reports, and study resources following the **Computer Science and Engineering (CSE)** curriculum at **International Islamic University Chittagong (IIUC)**.

> 🌟 If this repo helped you, consider giving it a star — it helps others find it too!

## 📌 Repository Overview

This repository is designed to keep all IIUC CSE academic programming coursework, lab assignments, and project reports organized and accessible. Whether you are reviewing fundamental concepts, looking for lab report guidelines, or preparing for lab exams, you can browse materials organized by semester and course code.

## 🚀 How to Use

1. **Clone the repository:**

    git clone https://github.com/Tofayel5152/CSE_study.git

2. **Navigate to the target directory:**

    cd CSE_study

## 🐛 Reporting Errors & Contributions

If you find any incorrect code, missing lab reports, broken links, or syllabus discrepancies, please report them so they can be updated:

* **Option 1 (GitHub Issues):** [Open a GitHub Issue](https://github.com/Tofayel5152/CSE_study/issues) describing the error or submit a Pull Request.
* **Option 2 (Direct Contact):** Send a direct message with details via Facebook or any other socials.

All contributions, missing report additions, and corrections are welcome!
